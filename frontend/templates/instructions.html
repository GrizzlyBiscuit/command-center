Install Local LLMs

Common options for running models locally:

  • Ollama: ollama pull model-name — then use that model with local runners.
  • Docker (container): docker run -p 5000:5000 my-llm-image
  • HF Transformers: install Python packages and run a small server: pip install transformers accelerate

Troubleshooting & Tips

  • Use `python -m pip install -r requirements.txt` in the project folder to ensure dependencies are installed.
  • If the UI cannot connect to a model, check the model server's host/port and set environment variables accordingly.
  • For Windows, use the desktop shortcut to launch the app and open the UI automatically.
